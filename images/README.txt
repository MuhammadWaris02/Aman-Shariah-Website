This folder is reserved for local image assets (logo, favicon, office photos,
team headshots, event photography, certificate scans).

The demo currently loads placeholder photography from picsum.photos and
placeholder avatars from i.pravatar.cc so the site works instantly with zero
setup. Before launch, replace the <img src="..."> and background-image URLs
across the HTML/CSS files with real files placed in this folder, e.g.:
  images/logo.svg
  images/hero-home.jpg
  images/team-adviser-1.jpg
